Core Entities

1. VendingMachine -> Orchestrator
2. Inventory -> Manages the inventory of products
3. Item -> Represents a product with its details (name, price, quantity)
4. Coin -> Represents a coin with its denomination
5. VendingMachineState -> Represents the state of the vending machine (e.g., Idle, HasMoney, Dispensing)


Class Design

VendingMachine
   - inventory: Inventory
   - balance: float
   - vendingMachineState: VendingMachineState
   - selectedItemCode: String

   + selectProduct(itemCode: String): void
   + insertCoin(coin: Coin): void
   + addBalance(amount: float): void
   + dispenseProduct(): void
   + refund(): void
   + reset(): void
   + getBalance(): float
   + getInventory(): Inventory
   + setVendingMachineState(state: VendingMachineState): void
   + getVendingMachineState(): VendingMachineState

Inventory
    - stockMap: HashMap<String, int>
    - ItemMap: HashMap<String, Item>

    + addItem(String itemCode, Item item, int quantity): void
    + removeItem(String itemCode, int quantity): void
    + getItem(String itemCode): Item
    + getQuantity(String itemCode): int
    + isInStock(String itemCode): boolean

Item
   - name: String
   - price: float

   + getName(): String
   + getPrice(): float

VendingMachineState:
    + insertCoin(coin: Coin): void
    + selectProduct(itemCode: String): void
    + dispense(): void
    + refund(): void
